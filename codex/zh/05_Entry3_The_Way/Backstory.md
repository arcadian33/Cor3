# 背景故事（Backstory）

火星……我花了不少时间才来到这里。也费了不小的力气。我从没问过自己这一切是否真的值得。像我这样没有明确目标的人，和这些人牵扯得这么深，大概是个非常糟糕的选择。但与此同时……我已经当了好一阵子滚石了，所以不管怎么说，这也算是一口新鲜空气。

就在几个月前，我还有点被困在我那间“旧”铺位里。我干各种杂活已经好一阵子了，凭我接过的那些活儿……嗯，说实话，能列出来的名单已经越来越短了。

私家侦探——这主意听着超酷，尤其对我这种人来说，人生经验丰富。去认识新朋友！揭开秘密！拿到报酬！梦想中的工作。但我并不抱太大期望，因为干这行的人得有人脉，而我并没有。只有我那段前雇佣兵的经历，以及在警队里待过的一些经验，给了我一点希望。

不过就像有人对我说的——不试试怎么知道！

所以，当我从 History Unfolded 那帮人手里接到工作邀约时……这么说吧，我又惊又兴奋。

他们发给我的合同真的很古怪，老实说，还自相矛盾。可我又有什么资格去质疑呢？毕竟，他们还给我派了一位非常漂亮的上线，名叫“Aurana Strogova”。

说实话——她一开始对我非常冷淡。不只是“职业化”的那种冷，我甚至感觉到某种敌意。

但这没造成多大影响。任务开始一个接一个地来了。

我的工作是挖出一些埋得足够深的旧秘密，深到“普通人”根本找不到。但显然，这对我来说不算太难。唯一的问题是，每次我挖出点什么，都感觉 Aurana 早就知道了。

这是在测试我的本事吗？这个念头不止一次地找上我。但我还是继续干下去，因为这对我来说是“世上最好的工作”。

最初的成果相当吓人——生化试验、作物实验、失控的机器人、武器测试失败……妈的，连失踪的 CORE 船员都在里面。所有这些事件看起来都相当随机，直到我开始看出其中的规律。

有某个人、或者某种东西，正为了不明的目的在编排所有这些事件。每一桩“谜案”都牵涉到某个要人：Usol、Soyuz、Terra Mater……甚至 CORE 本身！天啊，赌注一下子变得极高。

但我没有退出。到这一步已经很明显，被考验的不是我的能力，而是我的品性。我必须向雇主证明自己，也必须弄清他们究竟是谁。

于是我更加拼命地工作。真的把自己整个投了进去。不只是因为不得不做，而是因为这些故事本身就让人兴奋。谁能想到呢……

每一个故事都回答了更多问题，却也引出了更多问题。

那些“耦合体”（The Couplings）——是外星造物，还是被人动过手脚？和我谈过的那个人没说出多少东西，看起来是条死胡同，但他给了我一些有用的信息，让我明白那似乎是一次失败的“Razvedka”（侦察）行动的一部分。又或者，是有人想让它看起来像那样？

之后是 Astrocrop。妈的，那帮人。他们绝对是和魔鬼做了交易，否则我想不出谁能干出那种疯事。

找解药？呵，更像是试验更多、更离奇的异域手段，用来清洗一颗行星或某个小行星殖民地的人口。再把这套东西和宗教、意识形态混在一起，事情就更糟了。我纳闷为什么没人阻止他们，而 CORE 到底对这一切知道多少……

接下来是“Project Artemis”（阿尔忒弥斯计划）。又是 CORE，在研制大规模毁灭性武器，当然是为了和平与繁荣。我找到了他们的研发综合体，但那地方进不去。

再加上一段音频日志，清楚显示他们在运输途中丢了一件“装置”……更有理由兴奋了。

最后是那场著名的“Sky Lift”（天梯）。好几种说法、大量文件、证人供词……依然没有定论。我从里面唯一得到的确定是：那既不是单纯的事故，也不是什么“巧合”或别的什么。所有的迹象都表明它是被策划的。至于是谁策划的——那才是个好问题。

但所有这些努力都没有白费。

首先——我现在知道了地点——火星。一切都与那里有关。载着那些耦合体经过的 REPNODE-M7 空间站，“世代农场”（Generational Farm）——一个大型 Astrocrop 农业综合体，“Gobbler”前哨——一处 CORE 武器试验场，最后还有天梯本身。所有这些要么就在那颗行星上，要么以某种方式与它相连。

还有，那些在太空中来回弹跳的古怪无线电传输，似乎也源自这里，尽管当时我没时间去深究。

但最重要的是，在我把这一切报告给 Aurana 之后，我感觉到……她身上传来的暖意。就好像她很高兴地确认，她没有看错我。

当然，他们对那些东西全都知情，而我的工作似乎除了测试我的能力之外，基本上就是让我熟悉这个故事。但我不介意。这对接下来要发生的事大概是必要的——他们决定让我搭船前往那个 REPNODE 空间站继续调查。看来我的雇主缺一个可以信任、不会退缩的人。而那个人就是我。到那时我已经下定决心，无论如何都要把这一切查个水落石出。

唯一剩下的谜团是——我究竟在为谁工作。我没有直接问，指望他们会主动告诉我，但他们一直没说，直到我登上了那艘船……

我原本希望这段航程平安无事，因为很明显，合同的延续会耗费同样多（如果不是更多）的力气，但我想我的雇主另有安排。

一桩“失踪人口”案落到了我手里。一个完全陌生的人，名叫 Vladimir Semakin，他在 CORIE 就业中心看到了我“找活儿干的私家侦探”页面，于是联系我，请我帮他找一个叫 Jean 的姑娘——她在一连串颇具威胁性的情况下失踪了。

要是我当时知道就好了……

那桩案子把我引向了几个新的团体，我和他们多少混熟了：Gravers、PALIMPEST，还有其他几个我现在能称之为朋友的家伙（也许没那么好）。

而那个姑娘，Jean Flanders，恰好是 Exar-Solis 首席技术官的女儿。一个叛逆的孩子，知道得太多，正面临被人当作棋子的危险。

那个“某人”恰好就是 James “Jack” Curtis Fung 先生。一个真正的幽灵，找到他费了我很大的力气，而在我找到之后……这么说吧，我欠了某个人一份人情，而没人愿意欠那个人的人情。

他是个威胁，一个非常危险的人，但尽管我不愿承认——他也可能成为非常有用的资产。唯一的问题是，到这一步，我成了他的资产，而我不知道他会向我要求什么。

但是，正是他帮我查清了 Jean 的真相——她逃了出去，为自己挣得了一种新生活，一种有目标的生活。她成了另一个人。她成了 Aurana。

而就在那时我全明白了——我的雇主，我真正的雇主，Osiris 公司，找的是不仅有能力、意志坚定，而且与他们志同道合的人。

我以前从没多想过这件事，但发现真相，无论代价如何，让我感到快乐。这份工作给了我人生的目标，就像它给了 Aurana 一样。当然，Vladimir 也是，因为他显然也是他们中的一员。实际上他是个招募人，任务就是对我给出一个第三方的评价。

所以，我们到了。马上就要降落在 REPNODE-M7，以一名伪装成 CEDRT 工程师的身份继续我的旅程。我觉得现在我真的准备好了。我有我的团队，我有我的本事和人脉。剩下的只是完成任务所需的合适工具。所以，我就从那里开始。
