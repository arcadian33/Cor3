# 势力详解

## Soyuz

- **名称**：Soyuz（条目内均为大写 SOYUZ）
- **类型**：Major faction（太阳系主要阵营之一），条目分类仍是 Companies/Factions
- **总部 / 活动区域**：原文未说明具体总部；活动范围指向整个太阳系，并明确以「突破太阳系边界」为目标
- **业务或宗旨**：以「communion（共融）」与「combined effort（协力）」为立身原则；目标是为人类寻找一处永久的新家园。自我定位是太空先驱、殖民者与空间站建造者。一切努力都指向冲破太阳系边界、找到新家
- **已知历史事件**：原文未说明具体事件
- **与其他势力的关系**：与 USOL 敌对（见 USOL 条目，USOL 将 SOYUZ 与 Terra Mater 并列为「外部共同敌人」）；本条目未直接提及
- **标志性人物**：原文未说明
- **关键设定事实**：组织原则是集体协力而非竞争；「寻找新家园」是其存在理由，属于向外扩张型阵营；其经济/建设链条由 Starprom、Stroika Development、Lerp Express 三家公司承载（见各自条目）

## USOL

- **名称**：USOL
- **类型**：Major faction（太阳系主要阵营之一）
- **总部 / 活动区域**：无固定殖民母星式总部；势力依托**空间站与 asteroid（小行星）基地**，而非殖民地
- **业务或宗旨**：以「一切方面的自由」为原则，全面奉行「适者生存」的作风；内部靠竞争驱动，对外靠共同敌人维系团结。计划是把太阳系「用到极限」，不为遥远的未来打算，并且极擅长把这一理念变现
- **已知历史事件**：原文未说明具体事件
- **与其他势力的关系**：**敌对** SOYUZ 与 Terra Mater（原文称二者为其「outer adversaries」，是维系其内部团结的外部敌人）；Exar Solis 是其创始成员兼执行企业；Paradigm 名义上为其附属公司
- **标志性人物**：原文未说明
- **关键设定事实**：内部竞争 + 外部对抗的双重凝聚结构；不建殖民地、只建站与小行星基地，是与其他阵营的形态差异；短期榨取式的发展观被明确写成其「擅长」之事

## CADL

- **名称**：CADL
- **类型**：CORE 的行政分支（administrative branch）
- **总部 / 活动区域**：隶属 CORE，原文未说明具体地点
- **业务或宗旨**：主要做官僚 / 行政事务（bureaucracy），同时**负责阵营外交**
- **已知历史事件**：原文未说明
- **与其他势力的关系**：CORE 体系成员；因掌管外交，是与各阵营打交道的官方窗口（此处为职能推论，原文仅写「responsible for faction diplomacy」）
- **标志性人物**：原文未说明
- **关键设定事实**：把「官僚」与「外交」放在同一分支，暗示 CORE 的对外关系是行政化、程序化的

## CCS

- **名称**：CCS，全称 **Core Colonial Structure**
- **类型**：CORE 的分支，负责殖民事务
- **总部 / 活动区域**：随殖民地流动；业务覆盖「人类所有的殖民地」
- **业务或宗旨**：负责各殖民地早期开拓作业——通常是**第一批进场**的人，负责把基础设施准备好
- **已知历史事件**：原文未说明
- **与其他势力的关系**：CORE 体系成员；与所有殖民活动方（如 SOYUZ 的建设方）存在作业衔接，但原文未点名任何具体关系
- **标志性人物**：原文未说明
- **关键设定事实**：条目直接给出评价——「True heroes of humanity（人类的真英雄）」，是全部 14 条中唯一带明显褒义定性的组织

## Core Tech

- **名称**：Core Tech（条目内写作 CORE Tech）
- **类型**：CORE 的技术分支 / 技术持有实体
- **总部 / 活动区域**：原文未说明
- **业务或宗旨**：**技术的秘密持有者**。取得、开发并分发人类整体所拥有的绝大部分技术；同时对用这些技术制造的产品行使**管控者**职能——前提是这些产品被判定为重要或具潜在危险
- **已知历史事件**：原文未说明
- **与其他势力的关系**：CORE 体系核心；向 Viibot 提供 DTJC 技术；Core Arms「mostly use the technologies provided by CORE Tech」——是 CORE 军工的上游技术供应方
- **标志性人物**：原文未说明
- **关键设定事实**：它不是单纯研发机构，而是「技术闸门」：掌握分发权与制品审查权。DTJC 这一技术名称仅在本条与 Viibot 条出现，原文未解释其含义

## Core Arms

- **名称**：Core Arms
- **类型**：CORE 的军事技术研发分支（military technology research and development branch）
- **总部 / 活动区域**：原文未说明
- **业务或宗旨**：为 CORE 研发与生产各类科幻枪械与装备；技术上**主要采用 CORE Tech 提供的技术**
- **已知历史事件**：原文未说明

## Starprom

- **名称**：Starprom（Starprom Industries）
- **类型**：公司；SOYUZ 阵营的「backbone（脊梁）」
- **总部 / 活动区域**：原文未说明；供货范围覆盖太阳系（作为 SOYUZ 工业主体）

- **已知历史事件**：原文未说明
- **与其他势力的关系**：SOYUZ 阵营的核心工业成员
- **标志性人物**：原文未说明
- **关键设定事实**：「backbone of the SOYUZ faction」把它定义为 SOYUZ 的物质基础；与 Stroika Development（建造）、Lerp Express（运输轨道）构成 SOYUZ 的产业分工

## Stroika Development

- **名称**：Stroika Development
- **类型**：公司；SOYUZ 民用开发与重建服务商
- **总部 / 活动区域**：原文未说明；作品遍布「任何地方」
- **业务或宗旨**：SOYUZ 最大的**民用开发商**与**重建服务提供者**。条目以全大写强调「THEY BUILD. Like that.」——即纯粹以「建造」为本业

- **标志性人物**：原文未说明
- **关键设定事实**：判定法则——「任何地方任何一栋 SOYUZ 设计的建筑，多半是他们盖的」，说明 SOYUZ 的建筑标准由该公司实际落地。「reconstruction service」暗示此前存在需要重建的破坏，但原文未展开

# 势力关系网

## 一、CORE 体系（行政—技术—武力—殖民 四支）

```
              ┌──────────── CORE ────────────┐
              │                              │
   CADL（官僚＋外交）   Core Tech（技术闸门）   CCS（殖民先遣）
                              │
                        Core Arms（军工）
```

- **Core Tech → Core Arms**：技术供应（Core Arms「mostly use the technologies provided by CORE Tech」）。
- **Core Tech → Viibot**：提供 DTJC 技术，Viibot 的无人机/仿生人建立在此之上。
- **CADL ↔ 各阵营**：唯一被明确赋予「faction diplomacy」职能的机构，是 CORE 对外交涉的正式接口。
- **CCS ↔ 各殖民地**：为所有殖民地做前期基建，是 CORE 伸向各阵营殖民地的实际触手。
- 结构特征：CORE 不靠单一巨企，而是把**程序（CADL）、技术（Core Tech）、武力（Core Arms）、落地（CCS）**拆成四条互不重叠的分支。

## 二、SOYUZ 阵营（理念 + 完整产业链）

| 成员 | 在链条中的位置 |
| --- | --- |
| Soyuz | 阵营本体：理念（共融/协力）与目标（寻找新家园、突破太阳系边界） |
| Starprom | 上游：金属、复合材料、机械、太空建造，什么都造 |
| Stroika Development | 中游：民用开发与重建，把设计变成建筑 |
| Lerp Express | 动脉：铁路与单轨，几乎垄断全太阳系 |

- 这是一个**自洽的闭环**：材料（Starprom）→ 建造（Stroika）→ 运输（Lerp Express）→ 由 Soyuz 输出殖民与空间站。
- 三家成员条目都不写总部，只写「任何地方 / 整个太阳系」，与 Soyuz「向外突破」的宗旨一致。

## 三、USOL 阵营（自由 + 内竞 + 外敌）

| 成员 | 关系性质 |
| --- | --- |
| USOL | 阵营本体：适者生存、内部竞争、以空间站与小行星基地为依托 |
| Exar Solis | **创始成员 + 执行企业**：为阵营提供能源底座并代为执行 |
| Paradigm | **官方附属**，但传闻暗通 Osiris（双重效忠的裂缝） |

- USOL 的团结来自**外部敌人**而非内部认同：SOYUZ 与 Terra Mater 被明确列为「outer adversaries」。
- Paradigm 的「No questions asked」使其成为阵营内的**灰色出口**：官方归属 USOL，实际可能为 Osiris 服务。

## 四、对抗轴

| 对抗方 | 对手 | 原文依据 |
| --- | --- | --- |
| USOL | **SOYUZ** | USOL 条目将 SOYUZ 列为外部共同敌人 |
| USOL | **Terra Mater** | 同上（Terra Mater 不在本批 14 条内，仅被提及） |
| SOYUZ ↔ USOL | 理念对立 | SOYUZ＝共融协力 / 长期寻找新家园；USOL＝自由竞争 / 短期榨取太阳系 |
| CORE | 未表态 | CORE 各分支条目均未把任何阵营写作敌人；CADL 只「负责外交」 |

- 这条对抗轴是**理念级的**：一方要为人类找永久家园、愿意向外突破；一方要把现有太阳系榨到极限、不为未来打算。

## 五、渗透与灰色交易

- **Paradigm ⇢ Osiris（传闻）**：官方是 USOL 附属，传闻与 Osiris 是「朋友」。「No questions asked」政策使这种跨阵营的暗线在业务上完全可行。
- **CORE Tech 的技术许可网**：Viibot、Core Arms 均依赖其技术。凡「重要或可能危险」的制品，Core Tech 直接行使管控——这是一条**不靠武力、靠授权**的渗透路径。
- **Private Club**：为最富阶层提供 VIP 保护，客户横跨阵营；其效忠对象是财富而非旗帜（原文未说明其归属，此为对业务描述的归纳）。
- **Exar Solis 的「执行」角色**：作为 USOL 的执行企业，意味着阵营意志可通过公司渠道落地，而非只走官方机构。
