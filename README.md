## 关于图片文字

约 64 条条目的正文以图片形式存在（合同、审讯记录、蓝图、清单、新闻画面等）。这些图片已逐张**视觉转录并翻译成中文**，附在对应条目末尾的「## 图片文字（中文翻译）」小节里；纯照片则写「## 图片说明」。

无法辨认的地方一律标注 `[无法辨认]`，没有编造。部分条目源站的配图与标题本身不符（例如「密码」条目配的是弹药图纸），归档时按「以图为准」处理并保留说明。
